# 🎵 Music Player

Um player de música desenvolvido com **HTML, CSS e JavaScript**, criado para praticar desenvolvimento Front-End e manipulação de áudio no navegador.

## ✨ Funcionalidades

- ▶️ Play / Pause
- ⏮️ Música anterior
- ⏭️ Próxima música
- 🔀 Reprodução aleatória
- 🔄 Reiniciar música
- ❤️ Favoritar músicas
- ⏱️ Barra de progresso
